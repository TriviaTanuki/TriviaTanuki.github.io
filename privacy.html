プライバシーポリシー(TriviaEngine)

最終更新日: 2026年9月26日

1. このツールについて

TriviaEngine(以下「本ツール」)は、運営者「トリビアたぬき」が自分の YouTube チャンネルに動画を投稿するための個人用のツールです。一般の利用者向けには提供していません。

2. YouTube API サービスの利用

  • 本ツールは YouTube API サービスを利用しています。
  • 本ツールを使うことは、YouTube 利用規約に同意することを意味します。
  • Google による情報の取り扱いについては、Google プライバシーポリシーをご覧ください。
  • 本ツールが YouTube API サービスで行うのは、運営者が管理するチャンネルへの動画のアップロードと、投稿先チャンネルの確認(チャンネルIDの取得)だけです。

3. 取得・保存する情報

  • 運営者自身の Google アカウントで認可したときに発行される OAuth の認証情報(リフレッシュトークン)
  • 投稿先チャンネルを確認するためのチャンネルID
  • 本ツールが投稿した動画の ID・URL・投稿日時

運営者以外の方の個人情報は取得しません。視聴者のコメント・連絡先などの情報も取得しません。本ツールには利用者向けの画面が無いため、クッキーなどの情報を利用者の端末に保存したり、端末から読み取ったりすることはありません。

4. 利用目的

取得した情報は、運営者のチャンネルへの動画の投稿、投稿先チャンネルの取り違えの防止、同じ動画の二重投稿の防止にのみ使います。

5. 保存と共有

  • 認証情報は暗号化してデータベースに保存します。
  • 取得した情報を第三者に販売・共有・開示することはありません。

6. アクセスの取り消しとデータの削除

  • 本ツールへのアクセスは、Google アカウントのセキュリティ設定(サードパーティ アプリとサービス)からいつでも取り消せます。
  • アクセスが取り消された場合や本ツールの利用をやめた場合、保存している認証情報と YouTube API サービスから取得した情報は、7日以内に削除します。
  • 削除の依頼は、下記の連絡先でも受け付けます。

7. お問い合わせ

本ポリシーに関するお問い合わせ: triviatanuki@gmail.com

Privacy Policy (TriviaEngine)

Last updated: September 26, 2026

1. About this tool

TriviaEngine ("the Tool") is a personal tool used by the operator "Trivia Tanuki" to upload videos to the operator's own YouTube channels. It is not offered to the general public.

2. Use of YouTube API Services

  • The Tool uses YouTube API Services.
  • By using the Tool, you agree to be bound by the YouTube Terms of Service.
  • See the Google Privacy Policy for how Google handles information.
  • The Tool uses YouTube API Services only to upload videos to channels managed by the operator and to verify the destination channel (retrieving the channel ID).

3. Information we collect and store

  • OAuth credentials (refresh tokens) issued when the operator authorizes the Tool with the operator's own Google account
  • Channel IDs used to verify the destination channel
  • IDs, URLs and publish times of videos uploaded by the Tool

The Tool does not collect personal information of anyone other than the operator, including viewers' comments or contact details. The Tool has no user-facing interface and does not store or access cookies or any other information on users' devices.

4. How we use information

The information is used only to upload videos to the operator's channels, to prevent uploading to the wrong channel, and to prevent duplicate uploads.

5. Storage and sharing

  • Credentials are stored encrypted in a database.
  • We do not sell, share or disclose collected information to third parties.

6. Revoking access and data deletion

  • Access can be revoked at any time via the Google security settings page (third-party apps & services).
  • When access is revoked or the Tool is no longer used, the stored credentials and any information obtained through YouTube API Services are deleted within 7 days.
  • Deletion requests are also accepted at the contact address below.
