TriviaEngine

プライバシーポリシー / Privacy Policy

TriviaEngine は、運営者「トリビアたぬき」が自分の YouTube チャンネルに雑学の短い動画を投稿するための、個人用の自動化ツールです。一般の利用者向けのサービスではありません。

このツールは YouTube API サービスを使って、運営者自身が管理する YouTube チャンネルへの動画のアップロードと、投稿先チャンネルの確認を行います。データの取り扱いはプライバシーポリシーをご覧ください。

About (English)

TriviaEngine is a personal automation tool used by the operator "Trivia Tanuki" to upload short trivia videos to the operator's own YouTube channels. It is not a service offered to the general public. It uses YouTube API Services only to upload videos to, and verify the identity of, the channels listed above, which are owned and managed by the operator. See the Privacy Policy for how data is handled.
